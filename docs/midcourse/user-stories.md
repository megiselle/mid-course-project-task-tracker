# User Stories

## Feature 1: Tags / Labels

### User Story

As a user, I want to assign tags to tasks so that I can organize related work and identify important tasks quickly.

### Acceptance Criteria

- A task can be created with one or more tags.
- Tags are stored by the backend.
- Tags are returned by the API.
- Tags are displayed on the Kanban board.
- Tasks can have no tags.

---

## Feature 2: Search Tasks

### User Story

As a user, I want to search tasks by title so that I can quickly find relevant work items.

### Acceptance Criteria

- A search box is available on the Kanban board.
- Searching filters tasks by title.
- Filtering updates while typing.
- Clearing the search box restores all tasks.
- Search is case-insensitive.
